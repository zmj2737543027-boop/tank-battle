# 🎮 坦克大战 · Tank Battle

经典 FC《Battle City》致敬之作 —— 纯 HTML5 Canvas 实现的单文件坦克大战游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 玩法

- **目标**：摧毁地图上所有敌军坦克，守住基地（鹰标）不被攻破。
- **失败**：基地被摧毁、基地被敌人占领，或生命耗尽。
- **胜利**：清空当前关卡的全部敌人，进入下一关（共 3 关，可循环）。

## 操作

| 按键 | 功能 |
| --- | --- |
| `← ↑ ↓ →` 或 `W A S D` | 移动 |
| `空格` 或 `J` | 开火 |
| `P` 或 `Esc` | 暂停 / 继续 |
| `Enter` | 开始 / 过关继续 / 重开 |

## 游戏机制

- **地形**：砖墙（可摧毁）、钢墙（不可摧毁）、水域（坦克无法通过）、树林（坦克可藏身其下）。
- **敌军**：灰色普通、白色快速、红色装甲三种类型，从屏幕顶部三个出生点随机刷新（同屏最多 4 辆），出生时短暂无敌。
- **玩家**：出生及重生时短暂无敌（闪烁），拥有 3 条生命。
- **计分**：击毁敌军得分（普通 100 / 快速 200 / 装甲 300），最高分保存在浏览器 `localStorage`。
- **音效**：使用 Web Audio API 合成，无需外部资源。

## 运行

直接用浏览器打开 `index.html`，或将仓库部署到任意静态托管（GitHub Pages 等）。

本地开发调试：

```bash
# 无构建步骤；修改后直接在浏览器刷新即可
# 快速语法检查
node --check index.html   # 注意:需先抽取 <script> 内容
```

## 技术说明

- 单文件、零依赖：`index.html` 内含全部 HTML / CSS / JavaScript。
- 渲染：Canvas 2D，26×26 网格（每格 28px，画布 728×728），地图以 13×13 字符缩略图定义、程序化展开为 2×2 方块。
- 游戏循环：`requestAnimationFrame` 驱动 `update()` + `draw()`，60fps 帧计数。
- 关卡数据在 `LEVELS` 数组中，可按相同格式（每行 13 字符）自由扩展新关卡。
